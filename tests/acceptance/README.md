# 受け入れテスト

ここは「完成の判定」を置く場所。実装するエージェントは、このフォルダを変更しない。

- 人間が `ready` を付けた issue の受け入れ条件を、テストとして先にここへ書く(仕様を書く役の作業)。
- 実装するエージェントは、これを通るように実装する。テストの追加・変更・削除、`skip` の追加、期待値の緩和は禁止。
- 変更は、`protected-paths.json` と CODEOWNERS で保護されている。変更する場合は、人間が PR に `protected-change` ラベルを付ける。
- 閉じた issue の受け入れテストは、回帰テストとして残す(毎回の CI で動く)。

ファイルの命名と書き方は、スタックごとに違う(`docs/STACK.md`)。issue 番号を名前かコメントに入れる。
